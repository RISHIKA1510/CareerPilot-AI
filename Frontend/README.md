# CareerPilot AI – Frontend

CareerPilot AI is an AI-powered interview preparation and resume optimization platform. The frontend provides a responsive and user-friendly interface for personalized interview preparation.

## Features

- User registration, login and logout
- Resume upload in PDF format
- Job description analysis
- AI-generated technical and behavioral interview questions
- Personalized interview preparation strategy
- Job match score analysis
- Resume PDF generation and download
- Previous interview report history
- Responsive dark-themed dashboard

## Technologies Used

- React.js
- Vite
- JavaScript
- SCSS
- Axios
- React Router

## Local Setup

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:5173 in your browser.

Make sure the backend server is running on port 3000.

## Production Build

```bash
npm run build
```

## Deployment

The frontend is deployed using Vercel and communicates with the backend hosted on Render.
